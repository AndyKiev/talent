# People Review — презентація для HR-директора

## Завдання

PPTX-презентація модуля People Review українською для HR-директора. Червоно-зелена
(Auchan) палітра. Сесія №7 (id=7) — жива сесія з реальними даними як приклад.
Більше тексту про бізнес-логіку + більше скріншотів функціоналу.

## Файли

- `people_review_hr_director.pptx` — готовий deck, **12 слайдів**, 16:9.
- `people_review_hr_director.BACKUP.pptx` — оригінал (navy, 7 слайдів) до переробки.
- `build_deck.py` — генератор: перефарбовує BACKUP → червоно-зелений, додає слайди,
  вставляє скріншоти з `./shots/`. **Ідемпотентний** — щоразу будує з BACKUP.
- `shots/` — сюди кладемо PNG-скріншоти (див. ключі нижче), потім `python build_deck.py`.

## Скріншоти — 11 ключів (файли в `shots/<ключ>.png`)

1. `sessions_list` — `/people_review` грід сесій (pending/open/closed)
2. `roster_progress` — ростер сесії №7: статуси + дві шкали прогресу
3. `form_dimensions` — форма: виміри (компетенції) + факти
4. `form_level_plan` — форма: пропонований рівень + план розвитку
5. `dimension_panel` — панель однієї компетенції: зірочки, середнє, факти, діаграма
6. `proposed_level` — drawer пропонованого рівня + підсумок сильних/зон розвитку
7. `dev_plan` — план розвитку: місії + KPI
8. `roles_three` — один екран очима 3 ролей (через ScopeSettings-перемикач)
9. `report_pdf` — TEMPO PDF-альбом
10. `report_html` — TEMPO HTML-звіт
11. `presentation` — режим презентації / черга + аналітика сесії

**Як заповнити:** покласти PNG у `shots/` з відповідним ім'ям → `python build_deck.py`.
Наявні файли автоматично вставляються у плейсхолдери (fit по пропорціях, білий фон).

## Ролі (узгоджено)

- **only_me** — бачить лише власну форму
- **oversight** — бачить/заповнює форми призначених працівників (process roles)
- **supervisor** — бачить усі форми сесії
- Усі 3 демонструються під одним логіном **UKR7101004** через перемикач ScopeSettings.

## Що залишилось

Скріншоти (11 шт.) — потрібне **підключене розширення Claude in Chrome**
(зараз extension не під'єднано). Після під'єднання: зняти екрани під UKR7101004,
зберегти в `shots/` за ключами, перезапустити `build_deck.py`.
